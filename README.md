## Featured Systems

- **Realtime Feature Platform** ([repo](https://github.com/MustafaBulu/realtime-feature-platform)): Streaming feature platform for low-latency entity features from Kafka events, with Redis online serving and PostgreSQL request-time baseline checks. Local benchmark evidence: 24,000/24,000 events produced, consumer lag settled to 0, realtime k6 reads at 200 req/s with p95 4.03 ms, baseline p95 7.95 ms, and 20/20 correctness matches.
- **Payment Orchestration Platform** ([repo](https://github.com/MustafaBulu/banking-orchestration-platform)): Distributed payment system focused on correctness under asynchronous workflows. Uses DDD, Hexagonal Architecture, CQRS, Event Sourcing, Kafka, gRPC, PostgreSQL, durable sagas, transactional outbox, idempotent consumers, double-entry ledger posting, and tracing.
- **Billing Platform** ([repo](https://github.com/MustafaBulu/billing-platform-parent)): Multi-tenant usage-based billing platform covering tenant onboarding, usage ingestion, rating, invoicing, payment, and settlement. Includes Kafka orchestration, OpenAPI, Docker Compose, Kubernetes manifests, observability, k6 scenarios, and CI quality gates.
- **Flight Reservation Platform** ([repo](https://github.com/MustafaBulu/flight-reservation)): Reservation system built around concurrency-safe seat flows. Covers idempotency, rate limiting, indexed queries, Redis caching, Kubernetes/HPA, OpenTelemetry, Prometheus/Grafana, CI load-test gates, and security scans.
